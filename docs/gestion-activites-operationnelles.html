Gestion activités opérationnelles

La liste des tâches à traiter par une structure partenaire — les activités opérationnelles qui font avancer un processus métier après une rupture ou un changement d'acteur entre deux étapes.
Gestion activités opérationnelles v2.1 — 7 endpoints · 8 schémas
Base api.francetravail.io/partenaire/activites-operationnelles/v2
Une « to-do list » de structure. L'API liste les activités opérationnelles à traiter pour la structure identifiée — chaque activité étant une tâche datée, rattachée à un usager, avec des attributs de contexte. La pagination se fait par curseur.

Attributs spécifiques AttributSpecifique
0 ou plusieurs array · 0:N
Des paires nom/valeur qui contextualisent l'activité — et la relient aux autres processus (orientation, sanctions).
nom — typeParcours · typeOrganismeAccompagnateur · idConsequenceSanction · motif · codeInseeCommune · valeur
Prérequis — API du royaume /agent (client credentials). Les headers d'identification agent pa-nom-agent, pa-prenom-agent, pa-identifiant-agent sont obligatoires. La recherche est scopée à la structure identifiée, avec un filtre optionnel par numeroFranceTravail de l'usager.
Les attributs spécifiques font le pont avec d'autres API du parcours : typeParcours / typeOrganismeAccompagnateur renvoient à l'orientation, idConsequenceSanction aux sanctions.
Les types d'activité sont organisés sur trois niveaux — Domaine → Famille → Activité — consultables via les endpoints /referentiel-activites. Les libellés des codes ACTxxx se résolvent dans ce référentiel.
