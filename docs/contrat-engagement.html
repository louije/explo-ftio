Contrat d'engagement

Lire, signer ou refuser le contrat d'engagement réciproque d'un usager — le document qui formalise, depuis la loi pour le plein emploi, les engagements de l'usager et de son organisme référent.
Contrat d'engagement v1 — 6 endpoints · 9 schémas
Base api.francetravail.io/partenaire/contrat-engagement/v1
Un contrat réciproque. Le contrat lie deux parties : ce à quoi l'usager s'engage, et ce à quoi l'organisme (le conseiller référent) s'engage en retour. L'API permet de le lire, de récupérer le modèle vierge, et de le signer ou le refuser.

Unique object · 1:1
Pas du remplissage : la mention porte le texte légal réellement présenté à l'usager — les conséquences d'un non-respect (radiation, suppression des allocations, transmission au Conseil départemental pour le RSA) — et voiesRecours le droit de contester. Prérequis — API du royaume /agent (client credentials). Chaque appel nécessite le header ft-jeton-usager obtenu via l'API Rechercher usager, ainsi que les trois headers d'identification agent : pa-nom-agent, pa-prenom-agent, pa-identifiant-agent.
Dans le parcours « loi plein emploi » — le contrat d'engagement fait suite à l'orientation de l'usager vers un organisme. En cas de non-respect des engagements, les sanctions relèvent d'une API dédiée.
Le vocabulaire métier de l'API tient pour l'essentiel dans l'état du contrat, qui pilote le flux signer / refuser. Plusieurs champs juridiques (sanctions, articles, niveau de sanction) sont déclarés mais non renseignés pour le moment.

État du contrat 5 états ContratEngagement.etat

L'état détermine ce qu'on peut faire : un contrat A_SIGNER attend une première décision ; une fois SIGNE ou REFUSE, il peut être re-signé ou re-refusé.
Valeurs5
  • A_SIGNER Contrat à signer (première décision attendue)
  • EN_ATTENTE_SIGNATURE En attente de signature
  • SIGNE Signé par l'usager
  • REFUSE Refusé par l'usager
  • SUSPENDU Contrat suspendu
Les dates (dateSignature · dateRefus · dateSuspension) sont renseignées en cohérence avec l'état.

⚖️ Les mentions légales

Ce que le contrat dit des sanctions

La mention « Respect du contrat » est explicite : un non-respect expose à la radiation et à la suppression des allocations ; pour un allocataire du RSA, la radiation est transmise au Conseil départemental, qui peut suspendre le versement.

Les voies de recours garantissent le droit de présenter ses observations et de contester.

Texte réel issu du schéma. Les champs structurés sanctions[] / articles[] sont encore vides.
