ROME 4.0 — Métiers

Le référentiel navigable des métiers : parcourir et rechercher l'arbre des métiers ROME, leurs appellations, et tout ce qui s'y rattache (compétences, secteurs, centres d'intérêt, profil RIASEC, transitions).
ROME 4.0 - Métiers v1 — 17 endpoints · 20 schémas
Base api.francetravail.io/partenaire/rome-metiers
Une classification en arbre. Le ROME organise les professions sur quatre niveaux : Grand domaine → Domaine professionnel → Métier → Appellation. Chaque niveau a ses propres endpoints (lister / lire / rechercher). Le Métier est l'objet central — le modèle ci-dessous le détaille ; les autres niveaux et les facettes (secteurs, centres d'intérêt, thèmes) s'y rattachent.

Concepts partagés — Voir les concepts croisés entre APIs dans le catalogue
Cette API est un référentiel : l'essentiel de ses valeurs sont des codes de classification (métiers, domaines, secteurs…) servis par les endpoints eux-mêmes. Les vocabulaires ci-dessous sont les enum et conventions transverses à connaître pour interpréter et interroger les données.

Profil RIASEC 6 codes · codes de Holland riasecMajeur · riasecMineur

Le modèle RIASEC (typologie de Holland) décrit les intérêts professionnels. Chaque métier porte un code majeur et un code mineur, aussi utilisables comme filtres sur GET /metier.
Les 6 types6
  • R Réaliste — concret, manuel, technique
  • I Investigateur — analyse, recherche, résolution
  • A Artistique — création, expression, originalité
  • S Social — aide, enseignement, soin
  • E Entreprenant — direction, persuasion, vente
  • C Conventionnel — organisation, données, méthode
Filtres : riasec-majeur · riasec-mineur sur GET /v1/metiers/metier.

Syntaxe de requête recherche & sélection endpoints /requete et paramètre champs

Les endpoints metier/requete et appellation/requete exposent une recherche plein texte de type Solr. Tous les endpoints acceptent champs pour ne renvoyer que les attributs voulus.
Paramètres5
  • q Le(s) mot(s) ou début(s) de mot recherché(s)
  • qf Index de recherche (par défaut : code et libellé)
  • fq Filtres, ex. fq=code:1 AND (code:2 OR libelle:app)
  • op Opérateur entre mots multiples — OR (au moins un) ou AND (tous)
  • champs Sélecteur de champs retournés · date version du ROME à une date donnée
GET /v1/metiers/version renvoie la version courante du ROME (VersionRome : version · lastModifiedDate).

Du mot-clé au métier détaillé — Une application veut afficher la fiche d'un métier du numérique. Elle recherche d'abord « développeur » parmi les métiers, puis lit le métier retenu en demandant les champs utiles : appellations, profil RIASEC, compétences mobilisées et mobilité.

On lit le métier en demandant uniquement les champs utiles. Il se situe dans le grand domaine M — Support à l'entreprise, domaine M18.

La famille ROME 4.0 5 API navigation

Le référentiel des métiers et compétences : fiches, métiers, compétences, situations de travail, prédiction. Toutes décrivent le référentiel ROME 4.0 sous un angle différent ; chaque carte précise ce qui la distingue. Voir toutes les familles dans le catalogue.
ROME 4.0 - Compétencesv1
Le référentiel des compétences : chaque compétence avec son type, sa correspondance ESCO, ses macro-compétences et savoirs.
Métiers vs Compétences : Métiers liste les compétences mobilisées par métier ; Compétences décrit chaque compétence en profondeur.
ROME 4.0 - Métierscette page
Le référentiel navigable : parcourir l'arbre des métiers, rechercher, filtrer par RIASEC / NAF / compétence, et lire les métadonnées d'un métier (ISCO/ESCO, transitions, mobilité).
ROME V4.0 - Fiches ROMEv1
La fiche métier assemblée : pour un code ROME, les compétences groupées par enjeu et les savoirs groupés par catégorie.
Métiers vs Fiches ROME : Métiers liste quels métiers existent et leurs compétences à plat ; Fiches ROME structure compétences et savoirs (par enjeu et catégorie) pour un métier connu.
ROME V4.0 - Situations de travailv1
Le référentiel des situations de travail : contextes et conditions d'exercice (horaires, environnement, statuts).
Métiers vs Situations de travail : Métiers expose les contextes de travail d'un métier ; Situations de travail fournit le référentiel complet des contextes.
Romeov2.0
Le moteur de prédiction : à partir d'un texte libre, prédit le code métier ou compétence ROME le plus probable.
Métiers vs Romeo : Romeo prédit un code à partir de texte libre ; Métiers explore ensuite ce code dans le référentiel.
