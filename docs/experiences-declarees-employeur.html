Prérequis — API du royaume PE Connect (OAuth utilisateur). L'usager se connecte avec son compte France Travail et autorise le scope api_peconnect-experiencesprofessionellesdeclareesparlemployeurv1. L'application accède alors aux seules données de l'usager connecté.
Les filtres de GET /contrats permettent de restreindre la carrière retournée : dateDebutPeriode / dateFinPeriode, natureContrat, et dureeTravailMin avec son uniteDureeTravail.
Deux sources pour un même parcours. France Travail expose les expériences professionnelles d'un individu par deux API PE Connect distinctes. Elles ne se remplacent pas : l'une est déclarative, l'autre repose sur des justificatifs. Selon votre besoin — afficher un CV ou vérifier une carrière — vous appellerez l'une, l'autre, ou les deux.

Le fil conducteur : « ce que la personne dit » (son CV) versus « ce que France Travail a sur pièces » (les contrats déclarés par les employeurs).
Expériences déclarées par l'employeurcette page · 1 endpoint
La carrière reconstituée à partir des justificatifs employeurs transmis à France Travail. Données structurées et vérifiables : nature de contrat, niveau de qualification, et surtout l'employeur identifié (siret, codeApe, secteur, régime). Filtrable par période, nature de contrat et durée de travail. C'est la source à utiliser pour reconstituer ou contrôler un parcours sur pièces.
Expériences professionnelles (profil)1 endpoint
Le parcours saisi par l'usager dans son profil de compétences sur francetravail.fr. Données déclaratives et libres : description rédigée des missions, lieu, indicateur étranger, et même le bénévolat — des choses qu'un justificatif employeur n'a pas. Alimente le rapprochement CV ↔ offres.
Employeur vs Profil : l'employeur fournit des contrats officiels, factuels et datés au format administratif ; le profil fournit le récit que la personne a choisi de mettre en avant. L'un vérifie, l'autre valorise.
Quelle API appeler ? Reconstituer / contrôler une carrière sur pièces, avec employeurs identifiés → Expériences déclarées par l'employeur. Afficher le CV tel que rédigé par la personne (descriptions, lieux, bénévolat) → Expériences professionnelles. Les deux partagent le même royaume PE Connect : l'usager autorise chaque API séparément.
