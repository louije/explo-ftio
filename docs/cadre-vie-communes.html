Cadre de vie des communes

Pour un département donné, la liste de ses communes avec leur population, leurs coordonnées GPS, le nombre d'équipements par catégorie, et leurs communes voisines. Données issues d'eTerritoire.fr.
API Cadre de vie des communes v1.0.0 — 1 endpoint · 1 schéma
Base api.francetravail.io/partenaire/eterritoire/v1
Une recherche par département. On interroge un département (dep) et l'API renvoie un tableau de communes. Chaque commune décrit son cadre de vie : combien d'équipements de chaque type, où elle se situe, et ce qu'il y a autour.
Communes Commune[]
0 ou plusieurs array · 0:N
Identité et localisation
5 champs
L'identification de la commune et sa position. Le code INSEE est la clé pour la croiser avec d'autres référentiels.
idinsee ex. 84001 · nom ex. Althen-des-Paluds · pop — population ex. 2671
gps — tableau [latitude, longitude] · url — fiche commune sur eTerritoire.fr
Équipements equipements
Unique object · 1:1
Le nombre d'équipements de la commune, ventilé en cinq catégories. Ce sont des compteurs (entiers), pas la liste détaillée des équipements.
Équipements sportifs · Santé · Éducation · Loisirs · Services publics — chacun un entier
Communes à proximité proxycom
0 ou plusieurs array · 0:N
Les communes voisines, retournées uniquement si le paramètre proxycom est passé. Chaque voisine porte son nom, code postal et distance.
ncom — nom ex. Entraigues-sur-la-Sorgue · cp — code postal ex. 84320 · dista — distance
Prérequis — API du royaume partenaire (client credentials). Aucun ft-jeton-usager : ce sont des données publiques de territoire.
Croiser par commune — le idinsee est la clé pour relier cette commune à d'autres API où la commune est un objet de premier plan : le référentiel des communes d'Offres d'emploi (codes canoniques) · les statistiques du marché du travail par commune · les données de territoire (population active, établissements) via Informations sur un territoire.
