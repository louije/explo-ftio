Compétences professionnelles

Les compétences, langues et centres d'intérêt qu'un individu a saisis dans son profil de compétences sur francetravail.fr.
Compétences professionnelles v2.0.0 — 3 endpoints · 5 schémas
Base api.francetravail.io/partenaire/peconnect-competences/v2
Trois facettes, trois endpoints. L'API expose séparément les /competences, les /langues et les /interets de l'individu. Chacun renvoie une liste indépendante — il n'y a pas d'objet « profil » englobant.
Compétences Competence[]
0 ou plusieurs array · 0:N
Une compétence déclarée. Elle peut venir du référentiel ROME ou être saisie librement, et porte un niveau de maîtrise auto-évalué.
libelle · code — code ROME, présent uniquement si la compétence vient du référentiel
type — S issue du ROME · L saisie libre · Q savoir-être professionnel
niveau @ Niveau — 0 à 3 (Non évalué → Avancé)
Langues Langue[]
0 ou plusieurs array · 0:N
Les langues maîtrisées par l'individu, avec un niveau propre (échelle différente de celle des compétences).
code · libelle ex. Anglais
niveau @ NiveauLangue — 1 Débutant · 2 Intermédiaire · 3 Courant
Centres d'intérêt CentreInteret[]
0 ou plusieurs array · 0:N
Les centres d'intérêt déclarés, en texte libre — pas de référentiel ni de niveau ici.
intitule ex. Randonnée · complement — précision facultative
Prérequis — API du royaume PE Connect (OAuth utilisateur). L'individu se connecte avec son compte France Travail et autorise le scope authentification_individu. L'application accède aux seules données de l'usager connecté.

🧠 Compétences — trois origines

ROME, libre et savoir-être

Les trois types coexistent dans un même profil :

Concevoir une application web → S ROME (code 123456) · niveau Avancé
Veille technologique → L saisie libre (pas de code) · Intermédiaire
Travail en équipe → Q savoir-être · Non évalué
Seules les compétences de type S portent un code ROME.
🌍 Langues — échelle dédiée

Anglais courant, espagnol débutant

Les langues utilisent leur propre échelle 1–3 (Débutant → Courant), à ne pas confondre avec le 0–3 des compétences.

Anglais → Courant (3)
Espagnol → Débutant (1)
🎯 Centres d'intérêt — texte libre

Sans référentiel ni niveau

Randonnée → complément « Montagne et trail »
Open source → sans complément
Le complement est facultatif.
