PE Connect — Indemnisations

Savoir, en deux booléens, si un individu perçoit une allocation chômage ou des minima sociaux — sans détailler les montants. Typiquement pour ouvrir des aides liées au type de ressources.
API PE Connect - Indemnisations v1.0.0 — 1 endpoint · 1 schéma
Base api.francetravail.io/partenaire/peconnect-indemnisations/v1
Une réponse minimale et volontairement non détaillée. L'API ne dit pas combien ni quelle allocation précise : juste deux drapeaux oui/non. C'est une réponse pensée pour la confidentialité — assez pour déclencher une aide, pas assez pour profiler les ressources.
Indemnisation Indemnisation
Unique object · 1:1
Assurance chômage beneficiaireAssuranceChomage
booléen
Vrai si l'individu perçoit une allocation de l'assurance chômage — l'ARE (retour à l'emploi) ou l'ASP (sécurisation professionnelle).
beneficiaireAssuranceChomage — boolean
Prestations de solidarité beneficiairePrestationSolidarite
booléen
Vrai si l'individu bénéficie d'un ou plusieurs minima sociaux — AAH, ASS, RSA ou AER.
beneficiairePrestationSolidarite — boolean
Prérequis — API du royaume PE Connect (OAuth utilisateur). L'individu se connecte avec son compte France Travail et autorise le scope authentification_individu. L'application accède aux seules données de l'usager connecté.
Les deux booléens regroupent chacun plusieurs dispositifs. L'API ne distingue pas lequel : elle indique seulement la catégorie. Voici ce que chaque drapeau recouvre.

Dispositifs couverts 2 catégories schéma Indemnisation

Assurance chômage2
  • ARE Allocation d'aide au retour à l'emploi
  • ASP Allocation de sécurisation professionnelle
beneficiaireAssuranceChomage = true si l'un de ces dispositifs s'applique.
Minima sociaux4
  • AAH Allocation aux adultes handicapés
  • ASS Allocation de solidarité spécifique
  • RSA Revenu de solidarité active
  • AER Allocation équivalent retraite
beneficiairePrestationSolidarite = true si l'un de ces dispositifs s'applique.

Indemnisation — deux booléens (assurance chômage · solidarité)
Deux situations, deux réponses — Une application d'aides vérifie le type de ressources de l'usager connecté. Selon le cas, elle débloque une aide réservée aux allocataires de minima sociaux.
// GET /indemnisation // ── OAuth PE Connect · Bearer … ── // Cas 1 : demandeur d'emploi indemnisé { "beneficiaireAssuranceChomage": true, "beneficiairePrestationSolidarite": false }
// GET /indemnisation // Cas 2 : allocataire du RSA { "beneficiaireAssuranceChomage": false, "beneficiairePrestationSolidarite": true }
💼 Cas 1 — indemnisé par l'assurance chômage

Demandeur d'emploi percevant l'ARE

Assurance chômage → oui
Minima sociaux → non
L'API ne précise pas s'il s'agit d'ARE ou d'ASP — seulement la catégorie.
